## 双页面视图
我的双页面视图是通过引入一个外部库来实现的,叫Swiper。

把上屏幕和下屏幕都包在swiper-slide类里面，交给swiper来控制，下面就是swiper的基本属性。
```html
<swiper :modules="modules"       这是导入的功能模块，modules由自己定义
        :direction="'vertical'"  划动方向为垂直
        :slidesPerView="1"       一次可见的幻灯片数量为 1
        :speed="600"             幻灯片切换的过渡动画时长0.6秒
        :mousewheel="{ forceToAxis: true, releaseOnEdges: true }"
        @slideChange="onSlideChange"  当切换完成时触发函数
        class="fullpage-swiper"   类名称用来加css样式
        接下来的是一些拓展功能
        @swiper="onSwiperInit"    swiper加载好后触发函数
        :noSwipingClass="'scrollable-content'">   scrollable-content类内部可滚动
第一屏 
<swiper-slide class="slide-hero">
....
</swiper-slide>
第二屏 
<swiper-slide class="slide-main">
....
</swiper-slide>
</swiper>
```
其中modules是swiper中的功能模块，这里其实就引入了滚轮切换
```typescript
import { Mousewheel } from 'swiper/modules' 
const modules = [Mousewheel]
```
上面的html文档也直接启用了mousewheel模块，传入了两个参数：forceToAxis指的是强制在设定好的方向上即verticle(垂直),releaseOnEdges指的是当已经滑动到第一屏或最后一屏时，再往上往下滚也可以，但是显示出来什么就是浏览器的事情了。
```html
:mousewheel="{ forceToAxis: true, releaseOnEdges: true }"
```
每次切换完成都会触发onSlideChange函数，这个函数做了些什么呢？
```typescript
const onSlideChange = (swiper: any) => {
  if (swiper.activeIndex === 1) {    //在第一屏的时候
    isFirstScreen.value = false   //用来联动深色遮罩
    showAnimation.value = false   //先取false消除bug
    requestAnimationFrame(() => {  //下一帧再播放
    showAnimation.value = true     
    })
  } else {
    isFirstScreen.value = true
    showAnimation.value = false
  }
}
```
其中isFirstScreen和showAnimation都是用来联动动画表现的
```html
<Information class="info-card" :class="[showAnimation && 'animate__animated animate__fadeInLeft']" />
<player class="sticky-card" :class="[showAnimation && 'animate__animated animate__fadeInLeft animate__delay-1s']" style="--animate-delay: .15s;" />
```
通过:class动态绑定，当showAnimation为true,这个类就加上了animate__animated animate__fadeInLeft,变成class="info-card animate__animated animate__fadeInLeft"，实现动画的表现与否
```html
<Navbar :transparent="isFirstScreen" />
```
Navbar是我的导航栏组件，这个transparent的值由isFirstScreen决定，

```typescript
<script setup>
defineProps({
  transparent: Boolean   // 接收 true 或 false
})
</script>
<nav
    class="navbar"
    :class="{
      'navbar--transparent': transparent,
    }"
>
```
注意这里用的是大括号直接看transparent的返回值去看添加navbar--transparent这个类与否，另外nav是html的一个语意类标签，不是外部引入的库或是我自己定义的组件

前面的部分已经能实现上下屏跳转了，至于onSwiperInit和noSwipingClass其实是为了适配移动端还有实现网页记忆化。估计会在后面的文章里提到吧。
## 深色遮罩
这个深色遮罩其实就是一个css样式，由于我原来的背景是偏暖色调的，不太符合我的审美，所以我加了个这么个深色遮罩让色调偏冷一点。
```css
/*背景图片*/
.app-flex::before {
  content: '';
  position: fixed;             /*覆盖整个窗口*/
  top: 0; 
  left: 0;
  width: 100vw; 
  height: 100vh;
  background-image: url('@/assets/木叶创立.webp');
  background-size: cover;        /*等比缩放*/
  background-position: center;  /*居中对齐*/
  z-index: 0;                  /*放在底层*/
}
/*深色半透明遮罩*/
.app-flex::after {
  content: '';
  position: fixed;
  top: 0; 
  left: 0;
  width: 100vw; 
  height: 100vh;
  background: rgba(0, 0, 0, 0.45); /*黑色半透明*/
  z-index: 1;                  /* 覆盖在背景图之上*/
}
```
用了一个深色遮罩，45%透明度的伪元素卡片盖在了背景图上面。
## 波浪动画
```html
<svg class="waves" xmlns="http://www.w3.org/2000/svg" xmlns:xlink="http://www.w3.org/1999/xlink" viewBox="0 24 150 28"
  preserveAspectRatio="none" shape-rendering="auto">
  <defs>
    <path id="gentle-wave" d="M-160 44 c 30 0 58-18 88-18 s 58 18 88 18 58-18 88-18 58 18 88 18 v44 h-352 z" />
  </defs>
  <g class="parallax">
    <use xlink:href="#gentle-wave" x="48" y="0" fill="rgba(240,240,240,0.9)" />
    <use xlink:href="#gentle-wave" x="48" y="3" fill="rgba(240,240,240,0.7)" />
    <use xlink:href="#gentle-wave" x="48" y="5" fill="rgba(240,240,240,0.5)" />
    <use xlink:href="#gentle-wave" x="48" y="7" fill="#f0f0f0" />
  </g>
</svg>
```
借这个机会正好总结一下对svg图形的理解。

viewBow是指显示的区域0 24 150 28指的就是x轴上从0到150，y轴上从24到28，我们能看到的内容一般都是通过精心裁剪的。就像这里完整显示viewBox其实是-112 24 350 88

其中defs是图形模板库，来定义可复用的图形元素：path—路径、rect—矩形、circle—圆等等。

其中path是被用得最多的，path通过d即draw的缩写来描述形状。其中M是move-to的缩写，后面跟x和y坐标，表示从哪里开始

### 三次贝塞尔曲线
接下来的C和S要理解的话要搞明白三次贝塞尔曲线是个什么东西：一个画曲线的公式
C通过定义一个贝塞尔曲线，而S不断复用自动接续连上。v 44指向下画，h -352指向左画352个单位。

然后在g这个总图层里通过use调用这几个写好的path,给不同的y坐标位置。
最后呈现出来的静态样式就是这样的
![实际完整图形](/messages/5/white2.webp)

接着就是通过css实现动画效果了
```css
.parallax > use {
  animation: move-forever 25s cubic-bezier(0.55, 0.5, 0.45, 0.5) infinite;
}
.parallax > use:nth-child(1) { animation-delay: -2s; animation-duration: 7s; }
.parallax > use:nth-child(2) { animation-delay: -3s; animation-duration: 10s; }
.parallax > use:nth-child(3) { animation-delay: -4s; animation-duration: 13s; }
.parallax > use:nth-child(4) { animation-delay: -5s; animation-duration: 20s; }
```
animation有四个属性分别是名称，总时间，动画速度函数，播放次数

其中要解释的infinite是无限的意思，cubic-bezier(0.55, 0.5, 0.45, 0.5)
