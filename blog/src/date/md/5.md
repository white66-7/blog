## 双页面视图
我的双页面视图是通过引入一个外部库来实现的,叫Swiper。

把上屏幕和下屏幕都包在swiper-slide类里面，交给swiper来控制，下面就是swiper的基本属性。
```html
<swiper :modules="modules"       这是导入的功能模块，modules由自己定义
        :direction="'vertical'"  划动方向为垂直
        :slidesPerView="1"       一次可见的幻灯片数量为 1
        :speed="600"             幻灯片切换的过渡动画时长0.6秒
        :mousewheel="{ forceToAxis: true, releaseOnEdges: true }"
        @slideChange="onSlideChange"  当切换完成时触发函数
        class="fullpage-swiper"   类名称用来加css样式
        接下来的是一些拓展功能
        @swiper="onSwiperInit"    swiper加载好后触发函数
        :noSwipingClass="'scrollable-content'">   scrollable-content类内部可滚动
第一屏 
<swiper-slide class="slide-hero">
....
</swiper-slide>
第二屏 
<swiper-slide class="slide-main">
....
</swiper-slide>
</swiper>
```
其中modules是swiper中的功能模块，这里其实就引入了滚轮切换
```typescript
import { Mousewheel } from 'swiper/modules' 
const modules = [Mousewheel]
```
上面的html文档也直接启用了mousewheel模块，传入了两个参数：forceToAxis指的是强制在设定好的方向上即vertical(垂直),releaseOnEdges指的是当已经滑动到第一屏或最后一屏时，再往上往下滚也可以，但是显示出来什么就是浏览器的事情了。
```html
:mousewheel="{ forceToAxis: true, releaseOnEdges: true }"
```
每次切换完成都会触发onSlideChange函数，这个函数做了些什么呢？
```typescript
const onSlideChange = (swiper: any) => {
  if (swiper.activeIndex === 1) {    //在第一屏的时候
    isFirstScreen.value = false   //用来联动深色遮罩
    showAnimation.value = false   //先取false消除bug
    requestAnimationFrame(() => {  //下一帧再播放
    showAnimation.value = true     
    })
  } else {
    isFirstScreen.value = true
    showAnimation.value = false
  }
}
```
其中isFirstScreen和showAnimation都是用来联动动画表现的
```html
<Information class="info-card" :class="[showAnimation && 'animate__animated animate__fadeInLeft']" />
<player class="sticky-card" :class="[showAnimation && 'animate__animated animate__fadeInLeft animate__delay-1s']" style="--animate-delay: .15s;" />
```
通过:class动态绑定，当showAnimation为true,这个类就加上了animate__animated animate__fadeInLeft,变成class="info-card animate__animated animate__fadeInLeft"，实现动画的表现与否
```html
<Navbar :transparent="isFirstScreen" />
```
Navbar是我的导航栏组件，这个transparent的值由isFirstScreen决定，

```typescript
<script setup>
defineProps({
  transparent: Boolean   // 接收 true 或 false
})
</script>
<nav
    class="navbar"
    :class="{
      'navbar--transparent': transparent,
    }"
>
```
注意这里用的是大括号直接看 transparent的返回值去看添加 navbar--transparent这个类与否，另外 nav是 html的一个语意类标签，不是外部引入的库或是我自己定义的组件

前面的部分已经能实现上下屏跳转了，至于 onSwiperInit和 noSwipingClass其实是为了适配移动端还有实现网页记忆化。估计会在后面的文章里提到吧。

### 三次贝塞尔曲线
三次贝塞尔曲线是什么？这个其实偏数学一点。我觉得还蛮有意思的。简而言之一下就是画曲线的一个公式，不仅在这里的path有应用，而且在transition也会有用到：cubic-bezier来自己定义动画速度。

<a href="https://cubic-bezier.com/#.25,.1,.25,1" target="_blank" rel="noopener noreferrer">画三次贝塞尔曲线的网站</a>

原理是:一维插值算法即(1 - t)a + b表示在两点之间移动的点。

放到三个点的二维里面：把第一个点和第二个点所求的移动点当作起始点a，把第二个点和第三个点所求的移动点当作终止点b，在它两之间进行求移动点，就可以得到一条二维曲线

为了更精确但是有相对来说好算的一条波动曲线，一般取两个控制点。

在几何里面完全可以把控制点当作两个磁铁吸引着移动点的走势。该说不说这个还真有点像磁感线吧。
```html
c 30 0 58 -18 88 -18
```
这个点先按c定义出来的这条三次贝塞尔曲线一直移动
```html
s 58 18 88 18 58 -18 88 -18 58 18 88 18 
```
接着按s定义的三次贝塞尔曲线移动，这里定义了三段

不用c用s是因为s会自动计算第一个控制点，使曲线与前面的路径在连接处保持平滑
```html
v 44
```
v是vertical的缩写，这里表示垂直向下画 44个单位
```html
h -352
```
h则是Horizontal的缩写，表示水平向左画 352个单位

### css动画设置
接着是通过css实现动画效果了
```css
@keyframes move-forever {
  0% {
    transform: translate3d(-90px, 0, 0);
  }

  100% {
    transform: translate3d(85px, 0, 0);
  }
}
```
首先定义这样的一个动画，tanslate3d是三维平移，从一开始元素从初始位置向左偏移90px到最后元素移动到初始位置向右偏移 85px
```css
.parallax > use {
  animation: move-forever 25s cubic-bezier(0.55, 0.5, 0.45, 0.5) infinite;
}
.parallax > use:nth-child(1) { animation-delay: -2s; animation-duration: 7s; }
.parallax > use:nth-child(2) { animation-delay: -3s; animation-duration: 10s; }
.parallax > use:nth-child(3) { animation-delay: -4s; animation-duration: 13s; }
.parallax > use:nth-child(4) { animation-delay: -5s; animation-duration: 20s; }
```
animation有四个属性分别是名称，总时间，动画速度函数，播放次数。

这里的cubic-bezier(0.55, 0.5, 0.45, 0.5)是上方提到的自定义了一条动画速度函数：(0,0)到(1,1)中有两个自定义的点(0.55, 0.5)和(0.45, 0.5)影响这一条线形状。

一般是用内置的关键字比如linear：匀速，ease-in：缓入，ease-out：缓出，ease-in-out：缓入缓出。

.parallax > use指的这一整个图层都应用这里的animation设置，具体落实到每一条画出来路径上

:nth-child()表示按写出来的顺序选中对应的子元素即伪类选择器(按状态或排行)，为了体现层次感还有律动感所以设置了不同的动画起始时间和播放时间。
