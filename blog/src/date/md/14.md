## 本地大模型用途
以我的实际体验来说，本地大模型的能力受限于显存，是完全不能够和诸如DeepseekV4,Gemini studio，ChatGpt等相提并论的，再加上本地大模型的上下文并不能拉得很长，当一个完全了解你的私人助手也不现实。

我的想法是把大模型当作一个全能的工具箱，举个实际例子来说：我不喜欢微软初始的播放器，所以下了Potplayer当作默认播放器。Potplayer有一个插件可以实现实时字幕识别，但是实时字幕翻译功能却只能去请求百度翻译，Geogle Bing等各大翻译应用的api，要钱不说而且延迟极大，我们完全可以利用本地模型来实现翻译。

同样的思路，在未来，如果你要跑一些重复性的任务，同样可以如此。写一个脚本——把输入扔进本地模型，模型的输出取出来当结果。简单的预设是：扔进去一份mp3文件按照可以自由设定的文本格式生成这个音乐的字幕文件，扔进去一份未知语言的学术文本，生成一份翻译为中文的md/txt文件方便阅读。并且，这些操作在不开联网搜索的情况下离线就能使用，让你的显卡成为一个生产力工具。

重要的还是，等会要提到的Ollama，就是本地模型输入输出的媒介(不用在终端中输入输出)，听说生态还可以，GitHub上有许多有关这些的脚本。
## 本地大模型原理
听到在本地部署大模型，大部分人首先会在脑海里自动否定这个想法，认为自己的笔记本的显卡根本跑不动。在llama.cpp出来之前，这个想法是带有自知之明的正确。

<a href="https://github.com/ggml-org/llama.cpp" target='_blank' rel="noopener noreferrer">llama.cpp 源码</a>

然而，llama.cpp将这一切改变了。现在我对它的了解仅限于概念的水平，等到未来或许我会去学习一下架构和逻辑。它是一个特别的模型推理引擎，对于输入首先还是做常规的分词和嵌入，输出也靠常规的采样，中间的推理还是用Transformer，改动在于利用GGUF格式加载量化过后的所有权重参数，并且实时反量化，这样能省下许多运行空间；并且它靠调用CPU和GPU进行任务处理，能够减轻显卡压力。

老实说，我其实一直想知道大模型到底底层怎么实现的，上上学期在b站上看了看线性回归和梯度下降就没心思看下去了，现在的自己脑袋里空有一堆概念，我想大学总得花时间把这个疑惑解了。
## Ollama
Ollama是集成了llama.cp还有一站式部署的一个工具

<a href="https://ollama.com/" target='_blank' rel="noopener noreferrer">Ollama官网</a>

<a href="https://github.com/ollama/ollama" target='_blank' rel="noopener noreferrer">Ollama的Github地址</a>

在第一个官网网站上下载或者去Github仓库下载，这取决于下载速度。

接着在官网上找你感兴趣的大模型，拿我来举例子吧，我下载了translategemma的4b模型，这是Geogle专门对语言翻译微调的大模型，整个模型只有3.6G。我用于适配potplayer的实时翻译。

然后日常编码下载了gemma4的12b模型，专门用来理解代码，整体大小是7.6G，是R9000p的甜点模型。

下载模型的步骤是按Win键搜素终端,在里面输入对应训练集模型的下载代码。
```sh
ollama run gemma4:12b
```
等待跑到100%就可以使用。
## potplayer实时字幕设置
至于这个用来干嘛你别问。

先给potplayer加上这个插件

<a href="https://github.com/Nuo27/Potplayer-Ollama-Translate" target='_blank' rel="noopener noreferrer">插件下载地址</a>

下载解压好之后，选中potplayer的快捷启动方式，打开文件所在文件位置，打开Extension文件夹的Subtitle文件夹里的Translate，然后把解压出来的as和ico文件粘贴进去，具体的文件位置就在
```sh
C:\Program Files\DAUM\PotPlayer\Extension\Subtitle\Translate
```
然后打开potplayer，右键选中字幕，接着选中实时字幕翻译，打开里面的实时字幕翻译设置，把翻译引擎改成ollama

进入设置，在model里填写用来翻译模型的名字，Api keys一定要空着！！！如果你不清楚的话，可以在终端里输入
```sh
Ollama list
```
将输出的名称复制粘贴。

然后点击测试，如果跳出来potplayer可以支持实时翻译的弹窗，就说明你设置好了。

如果你觉得翻译延迟有点长，可以继续做接下来的步骤。

打开C:\Program Files\DAUM\PotPlayer\Extension\Subtitle\Translate路径下的SubtitleTranslate - ollama live translate.as文件，在50行左右找到这几个参数，改成下面的值。
```c++
bool enableThinking = false;
float temperature = 0.0;
float topP = 0.1;
```
