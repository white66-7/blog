## 回顾DFS和BFS
DFS和BFS是一种遍历手段,主要使用于树这个数据结构。其实是一种经过优化后的暴力手段。举个我当时理解入门的一个例子来说，给定一个迷宫，有很多错综复杂的路，老鼠从入口进入迷宫后只能通过暴力的搜索所有可能的道路，知道找到一个出口。

DFS： 可以看作是二叉树的正序遍历，这只老鼠每次遇到分叉路都往左边转。假设某一次左转后碰壁，那么就返回刚才的岔路口，这一次走右边，下次还是选择走左边，概括来说就是：一路到底，逐步回退。

BFS： 老鼠召唤无数的分身,在每个路口都派部分老鼠去探路,并且标记已经走过，如果碰壁或是碰到已经被标记的路就停下，概括来说就是: 全局出击，逐层递进。

BFS相比于DFS的优势在于能够最快输出最短路径。而在其他情况下这两个方法各有千秋。
## DFS框架和应用情境
dfs的实现手段是递归，理解起来有一定的难度。先给出框架吧
```C++
void dfs(...){
    if(到达目的地或是超出边界){
        更新答案;
        return;
    }
    for(用i来遍历下一层的所有可能)
    {
        if(visit[i] = 0) //只探索已经走过的路
        {
            visit[i] = 1; //标记
            dfs(...) //前往下一层
            vist[i] = 0; //!!! 恢复状态防止这层另外一种可能
        }
    }
    return;
}
```
最需要花费心力去理解的是visit[i] = 1后再vist[i] = 0这两个表达式。需要明白我注释的意思。

## BFS框架和应用情境
dfs的实现手段是队列，借助它先进先出。
```c++

```
例题是：马的遍历

有一个n X m的棋盘，在点(x,y)有一个马，要求马到达棋盘每一个点最少要几步。
```c++
int n,m;
struct node{
    int x,int y;
}
int dis[1000][1000] //存储最短距离
int vis[1000][1000] //标记数组
int dx[8] = {2,2,1,1,-1,-1,-2,-2}
int dy[8] = {1,-1,2,-1,2,-2,1,-1}
node s;
void main()
{
    cin >> n >> m >> s.x >> s.y;
    messet(dis,-1,sizeof(dis));
    dis[s.x][s.y] = 0;
    vis[s.x][s.y] = 1;
    queue<int> q; //队列
    q.push(s);
    while(!q.empty)
    {
        int now = q.front();
        q.pop();
        for (int i = 0;i<8;i++) //遍历所有下一层状态
        {
            node next;
            next.x = now.x + dx[i];
            next.y = now.y + dy[i];
            if(next.x < 0 || next.x > n) continue
            if(next.y < 0 || next.y > m) continue
            vis[next.x][next.y] = 1 //标记
            dis[next.x][next.y] = dis[now.x][now.y] + 1;
            q.push(next) 
        }
    }
    return;
    for(int i =0 ;i< n;i++)
    {
        for(int j = 0;j<m;j++)
        {
            print('%d\n',dis[i][j]);
        }
    }
}
```
## 邻接表存图
我认为这个对于bfs和dfs来说蛮重要的，一般都是先输入再遍历

在算法题中，如果有n个点m条边，你要存每个点连接了哪些点，就会用到这个
```c++
#include <bits/stdc++.h>
using namespace std;
const int n = 100005;
vector<int> g[n]; // g[i]存了所有与i相邻的节点
int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v; // u,v都是点 两个点之间有一条边
        cin >> u >> v;
        g[u].push_back(v); 
        g[v].push_back(u); 
    }
    return 0;
}
```
## 前缀和 
在输入时就进行和计算，可以省下很多时间

一维的来说：sum[i] = sum[i-1] + 输入的值

二维的来说：sum[x][y] =  sum[x][y-1]+ sum[x-1][y] -sum[x-1][y-1] + 输入的值

我个人认为这是一个纯理解性的东西，基本只能适用于一些特定的题目，不需要例题。所以这里就不放了。
## 差分
基本逻辑同上，但是用起来有点复杂，这个倒是需要要题目来理解。从我的经验来说的话，一般用于一维和二维的区间加减。

例题：棋盘

在n x n 的棋盘上,一开始棋盘上全是白子，即全为0，小轩进行了m次操作，每次操作会将棋盘上某个范围内的所有棋子的颜色取反，变为黑色，数值变为1。

请输出按输入对应的操作后的棋盘。输入的第一行包含两个整n和m，接下来m行，每行包含四个数x1，x2，y1，y2，表示取反的范围。
当然可以用暴力法，但这样只能解出30%的解
```c++
#include <iostream>
int a[2000][2000]
int main()
{
    int n,m;
    cin>>n>>m;
    for(int i = 0;i < m;i++)
    {
        int x1,x2,y1,y2;
        cin>>x1>>x2>>y1>>y2;
        for(int i = x1;i<x2,i++)
        {
            for(int j = y1;j<y2;j++)
            {
                a[i][j] ^= 1; //翻转最低位 即1变0 0变1
            }
        }
    }
    for(int i = 1;i<=n;i++)
    {
        for(int j = 1;j<=n;j++)
        {
            print('%d ',a[i][j]);
        }
    }
}
```
这样复杂度为O(mn²),怎么解决呢？
```c++
int d[2005][2005];  //差分数组
int main()
{
    int n,m;
    cin>>n>>m;
    for(int i = 0;i < m;i++)
    {
        int x1,x2,y1,y2;
        cin>>x1>>x2>>y1>>y2;
        insert(x1,y1,x2,y2);
    }
    for(int i = 1;i<=n;i++)
    {
        for(int j = 1;j<=n;j++)
        {
            d[i][j] = d[i][j] + d[i-1][j] + d[i][j-1] - d[i-1][j-1];
            print('%d ',a[i][j]);
        }
    }
}
void insert(int x1,int y1,int x2,int y2)
{
    d[x1][y1]++;
    d[x1][y2+1]--;
    d[x2 + 1][y1]--;
    d[x2+1][y2 + 1]++;
}
```
比较难理解的是这里的insert函数，它对差分数组做了些什么呢————标记。

当前格子的最终值 = 当前格子上的记号 + 左边格子的最终值 + 上边格子的最终值 - 左上角格子的最终值，前缀和从左到右，从上到下一路叠加，计算出这个格子的最终操作数目。

d[i][j] = d[i][j] + d[i-1][j] + d[i][j-1] - d[i-1][j-1];

    long long res = 1;

## 模运算
有关模运算有三条比较基础的准则
(a + b) % mod = (a % mod + b % mod) % mod

(a - b) % mod = (a % mod - b % mod + mod) % mod

(a * b) % mod = (a % mod) * (b % mod) % mod

现在介绍一下关于模运算相关知识：逆元还有费马小定理

对(b / a mod p)来说只能b除以a后再取模，但是还可以求出a的逆元，然后原式就等于b乘a的逆元再取模。

根据费马小定理，a的逆元为：a^(p-2) % p
```c++
const int MOD = 1e9 + 7;
// 快速幂
long long quick_pow(long long a, long long b) {
    long long res = 1;
    while (b) {
        if (b % 2 == 1) res = res * a % MOD;
        a = a * a % MOD;
        b /= 2;
    }
    return res;
}
// 求 a 的模逆元
long long inv(long long a) {
    return quick_pow(a, MOD - 2);
}
```
