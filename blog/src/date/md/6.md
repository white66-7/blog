## vue框架的支持组件
说到动画,就不得不提我用的最多的一个外部库animate.css,[实际动画演示网站](https://animate.style/)。

那么怎么用呢？在终端中直接用npm下载就好了,在终端中输入以下代码
```shell
npm i animate.css
```
接着在js代码中直接引用就好了
```javascript
import 'animate.css'
```
接着就是就是在html文档中操作了，我一般主要用两种方式。

第一种是: 假设你已经写好了一个小组件，那么就用一个div块把它包起来,在它的class属性中加上animate__animated告诉解析器用到了这个库。

接着写具体运用哪个动画效果，这个可以在我刚才给的网站中去挑选，然后复制你觉得还不错的动画的名字。

一般来说这样就可以简单应用了，但是一般来说一个页面有多个组件，为了让它呈现出ppt那种效果，就要用style中的animation-delay属性来限制动画的出现时间。
```html
<div class="animate__animated animate__fadeIn" style="animation-delay: 0.3s;">
```
那么第二种方法我一般是用于大组件，区别在于能实现更精细的效果和条件触发
```html
<ArticleShow :articles="articleData" :class="[
                showAnimation &&
                'animate__animated animate__fadeInUp animate__delay-1s'
              ]" style="--animate-delay: .3s;" />
import ArticleShow from '@/...'
```
首先在这个界面引用这个组件，接着在html文档中引用，绑定一个动态类，只有当showAnimation为true时，才会添加animate__animated animate__fadeInUp animate__delay-1s,也就是animate.css的三个基础类：激活动画类，动画效果类，延迟辅助类(默认1s)。

那么showAnimation什么时候为true呢?

这里就举我首页各组件还有文章界面的文章卡片的例子来说明。
```javascript
const showAnimation = ref(false)
const onSlideChange = (swiper: any) => {
  if (swiper.activeIndex === 1) {
    showAnimation.value = false
    requestAnimationFrame(() => {
      showAnimation.value = true
    })
  } else {
    showAnimation.value = false
  }
}
```
在我的首页中,我将其设置为当进入下界面就启动，退出则卸载掉。
由于一开始网站是在上页面，要将showAnimation设置为响应式数据false。

接着承接上文我所讲到的Swiper库，每次换上下页给了一个绑定函数，在这里是onSlideChange,换页之后进入if判断中，如果在第二页中就把showAnimation的值设置为true,触发动画，否则肯定在第一页，那么就不触发，把showAnimation的值设置为false。

值得一提的是，对于这种高速触发的事件，为了防止动画异常，不能直接设置为true,这里使用先设为false,接着在下一帧的时候设为true触发动画，基本防范了因为高速划动而产生的bug情况。

## 颜色填充与放大
这个效果是我觉得最舒服的，虽然我也不知道我舒服的原因。

实际演示效果可以参考我文章的每个目录，概述一下就是绿色从左往右填充，伴随整个按钮放大。
```css
.toc__item::before {
  content: "";
  position: absolute;
  top: 0;
  left: 0;
  height: 100%;
  width: 0;                         
  border-radius: 15px;
  background-color: #23c483;       
  z-index: -1;                    
  transition: width 0.3s ease;   
}
.toc__item:hover {
  color: #ffffff;                   
  transform: scale(1.10);     
}
.toc__item:hover::before {
  width: 100%;                    
}
```
定义一个绿色的伪元素，z-index我理解为一个3D属性，值越大则越在上层，这里设置为-1把它放到最底层防止覆盖实际显示文字。content有很多值：文字，图片(url)，或是html中的元素...，这里设置为空意思是生成一个0 x 0的盒子,接着我们着手去塑造这个盒子,位置对于父容器绝对定位，其中距离左侧和上侧的距离为0即放在左上角，高度100%适应父容器放大的效果。
一开始把它的宽度设置为0，所以显示不了，当toc__item类触发hover时，变大，文字变成白色接着这个伪元素宽度由0%变为100%，通过transition: width 0.3s ease这一个曲线动画表现。

## 悬浮阴影效果
这个老实说也还不错，演示效果可以参考文章主界面的一路向北的杂谈那几个字。

概述一下就是文字像是凭空浮起来了一样。
```css
.case-title .r {
  display: inline-block;
  margin-right: 0.3em;
  background: #f4ecd8;
  color: #111;
  padding: 0.05em 0.12em;
  font-size: clamp(2rem, 5vw, 3.5rem);
  font-weight: normal;
  box-shadow: 3px 3px 0 rgba(0, 0, 0, 0.2);
  white-space: nowrap;
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.case-title .r:hover {
  transform: translateY(-4px) rotate(0deg);
  box-shadow: 4px 6px 12px rgba(0, 0, 0, 0.25);
}
```
其实也很简单，就是hover后元素向上移4像素，然后角度回正，这个元素的阴影变得更深，就像是影子变深了。然后定义变化和阴影的表现效果为0.3秒的一个平滑曲线，这个几乎只要是动画就可以写一手，泛用性极其强大。

## 类似于书卷的翻开效果
在我主界面的随心一说和相册界面的相册集中都有用到这个效果

值得一提的是这不是单纯可复用的hover效果而是一整个组件的css样式
```css
/*相册堆叠主容器*/
.album-stack {
  position: relative;      /*子元素相对于它定位*/
  cursor: pointer;
  transition: transform 0.3s;
}
/*底层两张“假卡片”样式*/
.album-stack::before,
.album-stack::after {
  content: "";             
  position: absolute; 
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background: #fff;    
  border-radius: 2px;
  box-shadow: 0 2px 5px rgba(0, 0, 0, 0.1); 
  z-index: -1;          
  transition: all 0.3s;  
}
/*第一张假卡片*/
.album-stack::before {
  transform: rotate(-5deg);
  top: 2px;
  left: -4px;    
}
/*第二张假卡片*/
.album-stack::after {
  transform: rotate(4deg);
  top: 4px;
  left: 4px;        
}
/*hover效果 */

/*主卡片上浮*/
.album-stack:hover {
  transform: translateY(-10px) !important;
  z-index: 10;     
}
/*左假卡片更歪,向左下散开*/
.album-stack:hover::before {
  transform: rotate(-8deg) translate(-5px, 5px);
}
/*右假卡片更歪,向右下散开*/
.album-stack:hover::after {
  transform: rotate(8deg) translate(5px, 5px);
}
```
可以看到运用了两个伪元素纯白色的卡片放在底部，一个稍微在上方往左偏，一个稍微在下边往右偏。hover时为了达到散开的效果，x轴和y轴的数值更大而且偏转的角度更大。
