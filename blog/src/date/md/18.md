## 3D层级
CSS语法中有两个特性与3D有关，分别是z-index和tranfrom。这两个特性虽说基础，但能实现的效果很强大。

严格来说这其实算不上3D，其实是利用视觉透视和坐标变化模拟的立体空间感。

屏幕这个二维平面对应三维坐标系的x-y平面,z-index对应的就是z轴，由屏幕到你的这一条线。这意味着在同一个位置可以放置多个元素，我们通过设置元素的z-index大小控制遮挡关系组合出独特的样式。举个浅显的例子来说，相册页面书本打开后最下方是棕色书皮，中间是米白色页面，接着是白色相片纸，最上方是图片。这样的组合复刻了现实的相册。

tranfrom能做到的事情往往更多，并且我觉得通过一次实战就能掌握如何使用。

假设要画一个正方体，就需要6个面，需要一个容器来管理整体的透视并开启3D空间。而这些都需要挂载在DOM节点即html类上。

按照这个说法，html是这么写的。
```html
<!-- 容器 -->
<div class ="pillar"> 
    <div class = "face front"></div>
    <div class = "face back"></div>
    <div class = "face left"></div>
    <div class = "face right"></div>
    <div class = "face top"></div>
    <div class = "face bottom"></div>
</div>
```
于此对应，pillar作为容器需要开启三维空间方便子类定位。
```css
.pillar{
    position: relative;
    height: 42px;
    transform-style: preserve-3d;
    width: 42px;
}
```
最前面的面需要向前凸出
```css
.face.front{
    width: 100%;
    height: 42px;
    tranform: translateZ(9px);
    position: absolute;
}
```
后方的面需要旋转后向后凹，怎么理解这个旋转呢，和高中学的右手定则一样：伸出食指，绕X轴转则指向右方，绕Y轴转则指向上方，大拇指就是旋转路径。
```css
.face.back{
    width: 100%;
    height: 42px;
    tranform:  rotateY(180deg)  translateZ(-9px);
    position: absolute;
}
```
顶面则是以X轴转90度然后往上移动
```css
.face.top{
    width: 100%;
    height: 42px;
    tranform:  rotateX(90deg);
    top: 9px;
    position: absolute;
}
```
侧面是以Y轴旋转90度然后往右移动
```css
.face.top{
    width: 100%;
    height: 42px;
    tranform:  rotateY(90deg);
    right: 9px;
    position: absolute;
}
```
最后呈现出的效果就是这样的。我们可以给这个正方体转一个角度即给pillar类加一个旋转让来看的更清楚一些。我这里让它稍微低一点,往右偏一点；并且加上颜色和文字。

## 描字动画
这个是我从外网抄的，动画分成两个部分，第一部分是把文字边框显现出来，第二部分是将颜色填充。文字是一整个SVG元素，css对此有专门的特性。
```html
<!-- 这是文字SVG -->
<svg width="100%" height="100%" viewBox="0 0 800 200" xmlns="http://www.w3.org/2000/svg">
    <g class="animated-text">
        <path class="cls-1" pathLength="1"
            d='...' />
    </g>
</svg>
```
用到的特性是描边-stroke，就是图形轮廓的那一条线。初始时先将图形隐藏，即透明度为0，描边向下偏移。此时屏幕中什么都没有。这里有个小技巧是使用 pathLength="1" 将SVG长度强制设置为1，这样我们的stroke-dasharry与stroke-dashoffset就不用去借助js语句求精确的长度。
```css
.initial-loader .animated-text {
    stroke: #2c2c2c;
    stroke-width：14px;
    fill: transparent;
    stroke-dasharry: 1;  // 使用虚线的效果
    stroke-dashoffset: 1;
}
```
我们使用虚线的效果，并且将长度设置为1是为了形成一段空白和一段实线描边，借助stroke-dashoffset把实现往起点对应的数值，这样初始没有描边。如果我将偏移设置为一般的话，就会出现下面的情况，后半部分的描边到了前半部分，前半部分的描边看不到了。
<img src="/messages/18/true3.webp" alt="演示"/>

接着是定义一个专属动画
```css
@keyframes writetext{
    0%{
        fill: transparent;
        stroke-dashoffset: 1;
    }
    75%{
        fill: transparent;
        stroke-dashoffset: 0;
    }
    100%{
        fill: black;
        stroke-dashoffset: 0;
    }
}
```
接着应用这个动画
```css
.initial-loader .animated-text {
    ... //略
    animation: writetext 3s esse forwards; //停在最后一帧
}
```

### css
接着画这个火焰，需要用到css的clip-path + linear-gradient + filter三个特性。

clip-path翻译为剪裁路径，我们用至少三个点连成一个闭合图形，图形外的内容将直接被舍弃
```css
clip-path: polygon(50% 0%, 100% 100%, 0% 100%); //三角形
```

linear-gradient翻译是线性渐变，这里用来模拟火焰效果，用法和keyframes差不多,第一个参数是方向，后面的参数是变色节点
```css
background: linear-gradient(
    to bottom，
    white 0%,
    blue 50%,
    red 100% 
)
```

### javascript
Js代码用到了反正切函数与跨0度插值算法用于旋转角度，但这不是很重要
```javascript
const dx = mouseX - prevX; // 水平方向位移
const dy = mouseY - prevY; // 垂直方向位移

// 角度计算
targetAngle = (Math.atan2(dy, dx) * 180) / Math.PI + 90;

let diff = (targetAngle - shipAngle) % 360;
// 角度差大于 180 度，往反方向拐
if (diff > 180) diff -= 360;
if (diff < -180) diff += 360;

// 转角度差的20%
const turnRate = diff * 0.20;
shipAngle += turnRate;
```

重点是html绑定js,在html中通过ref定义一个可响应元素
```html
<div ref="shipRef" class="ship-wrapper">
```
再在js中拿到这个元素，设为null是预防一开始这个DOM没有加载出来。拿到后并操控这个DOM对应的css样式。
```javascript
const shipRef = ref(null)

shipRef.value.style.transform = `translate3d(...) rotate(...)`
```
其中用translate3d来控制移动，rotate来控制旋转。
