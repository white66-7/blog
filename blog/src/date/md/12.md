## 字体
首先是字体，在正常的项目中字体一般放在前端文件夹中。网络好的情况下，网页一下子加载出十MB级的ttf字体文件不成问题，网络差的情况下，会加载网页最为原始的字体。加载好后突然变成实际的字体。
### 转SVG图标
第一种解决办法是将带有显眼且无法变动这两个特点的区域的字体直接转为SVG形式，举个例子来说：我的入屏动画有一个"一路向北的站点"描写动画，这段文字每次进入网页都会播放让后台加载东西,完全就可以转为SVG形式。

为了应用这个方法，我使用的工具是PS，就是那个广为人知的批图软件。创建一个适宜宽高的透明画布，按T键创立一个文字区域，然后选一个喜欢的字体，接着右键转换为形状，最后选择导出为SVG就可以了。
![操作](/messages/12/text.webp)

这样会得到一个html格式的文件，选择用记事本打开复制全部的代码，这就是得到的SVG表达式。

哦对了,如果你要用的字体是从网上下载下来的，要右键安装，PS才会显示可用。
### 字体文件压缩
可这样还是避免不了加载字体文件，既然这样。可以把字体文件加载逻辑改一下，原本是一下子把全部加载出来然后逐个对应渲染，现在可以是每次要渲染哪些就拿哪些，缓存这些，下次要拿不必加载直接从缓存区里拿到。

实现下来要靠终端运行下面的语句
```bash
npx cn-font-split -i No.289-ShangShouJiangHuShuFaTi-2.ttf -o ./sliced-font
```
这里的命令符是npx原因是npx可以使用临时下载这里的cn-font-split到本地缓存，执行完语句就删掉，不占内存。-i后面对应的是你的字体文件全名，-o后面跟着的是下载到哪个文件夹中

然后去得到的文件夹中找一下result.css文件打开，看看它最后一行的font-family是什么
```css
font-family: "ShangShouJiangHuShuFa";
```
如果是Vue框架就去index.html的head中加个全局链接
```html
<link rel="stylesheet" href="/text/ancient-font/sliced-font/result.css">
```
后面想用这个字体直接引用font-family对应的值就好了。

如果觉得它font-family的值太难写了，也可以换成自己喜欢的，在result.css文件中按ctrl + F全局查找，输入font-family，然后把后面的值全部换成你想要的就可以了。

## 骨架屏
其实我觉得骨架屏是最有意思的，视觉效果很足，而且美观
### 基础逻辑
我的骨架屏是靠状态切换实现的，分为前端资源加载和后端资源加载。
```typescript
const avatarLoaded = ref(false)
```
```html
<div class="avatar-wrapper">
<!-- 骨架层 -->
    <div :class="['skeleton-avatar', { 'skeleton-hidden': avatarLoaded }]"></div>
<!-- 真实头像 -->
    <img
    class="avatar"
    :class="{ 'avatar-visible': avatarLoaded }"
    src="@/assets/me.jpg"
    loading="lazy"
    alt="头像"
    @load="avatarLoaded = true"
    @error="avatarLoaded = true"
    />
</div>
```
这就是前端资源的骨架屏，用一个状态变量来监视加载，这个变量决定是否添加skeleton-hidden这个类，关联起骨架动画的开关，当加载或失败时avatarLoaded变成true，透明度为0会隐藏。此时头像加上avatar-visible类，透明度为1完全显示。
```css
.skeleton-hidden {
  opacity: 0;
}
.avatar-visible {
  opacity: 1;
}
```
如果是后端资源，变量监控的是请求后端接口成不成功，
```typescript
const loading = ref(true)  //第1步：一开始是"加载中"
async function fetchCommitsTimeline() {
  try {
    const res = await fetch(API_URL)   //第2步：去后端要数据
    // ...数据处理...(省略)
    loading.value = false              //第3步：成功后关掉骨架
  } catch (err) {
    console.error(err)                //出错了骨架继续显示，在控制台打印错误信息
  }
}
```
```html
<!-- loading = true（请求中）就显示骨架 -->
<div v-if="loading" class="timeline skeleton-timeline">骨架占位</div>

<!-- loading = false（请求完毕）且groupedTimeline.length不为空(展示数组传入了数值)就显示真实内容 -->
<div v-else-if="groupedTimeline.length" class="timeline">真实时间线</div>

<!--loading = false（请求完毕）且数据为空就显示空提示 -->
<p v-else>No commits found yet.</p>
```
fetch是前端内置的一个函数，可以去后端给的地址拿数据。
### 绘制骨架
骨架要尽量复刻真实内容的布局和尺寸,拿图片来说是一个正方形或长方形。

<a href="https://www.bilibili.com/video/BV1J1421D7Py/?share_source=copy_web&vd_source=aa4072bc298a92b8ef0a2929fb1722c7" target="_blank" rel="noopener noreferrer">b站讲解</a>

linear-gradient用来创建线性渐变背景，90deg是90度指垂直方向上，在40%宽度处是一个颜色，50%宽度处是另一个颜色，在60%宽度上是另外一个颜色渐变。为了更直观，我把背景色调为绿色，可以看到下图有一道很明显的白色高光，接下来要做的就是让这个高光从左侧移动到右侧。
![操作](/messages/12/1.webp)
这里的实现办法是让背景图移动，先把背景宽度放大为原来的2倍，高度不变。此时高光会移动到右侧边缘(80%-120%)。
```css
@keyframes loading{
 0%{
  background-position: 100%;
 }
 100%{
  background-position: 0%;
 }
}
```
然后写一个动画把这个高光从左向右移动，值得一提的是，在css的坐标系中，向下和向右是正方向，这里的background-position用百分比计算的时候更是反直觉,不是原来的背景移动了多少，而是对齐点的匹配
，即背景图上的X%点对齐容器上的X%点。
```text
0% 的意思是背景图的左边缘对齐窗口的左边缘。
100% 的意思是背景图的右边缘对齐窗口的右边缘。
```
规律是百分比值越大，背景图往左跑，百分比值越小，背景图往右跑。

如果要画一个具体有布局的组件,比如我的贡献墙，全是小格子，那就根据原来的html文档对应地生成16像素的灰色正方形。
```html

  <div v-for="(row, rowIdx) in contributionGrid" :key="rowIdx" class="contrib-row">
    <div
      v-for="(count, colIdx) in row"
      :key="colIdx"
      class="contrib-cell"
      :class="getLevelClass(count)"                         ←根据贡献次数给格子加颜色等级
      :title="`${count} contribution${count !== 1 ? 's' : ''}`"  ←鼠标悬停显示具体贡献数
    ></div>
  </div>
</div>
```

这里我的背景图特别的换成有科技感的蓝光，并且全部的格子加上了呼吸动画，这样的蓝色扫光非常炫。

### 过度动画
如果数据加载好了突然就出现，效果就会变得很生硬。可以借助Animate.css库给组件做一个出现动画(我没尝试)，也可以换Transition：一个Vue3内置的动画组件。
```html
<Transition name="fade" mode="out-in">
  <!-- 骨架网格 -->
  <div v-if="!hasData" key="skeleton" class="skeleton-grid">...</div>
  <!-- 真实网格 -->
  <div v-else key="content" class="contrib-grid">...</div>
</Transition>
```
name是前缀，会自动生成下面这几个类。

| 类名 | 作用阶段 |
|------------------------------|----------|
| `fade-enter-from` | 元素被插入前的初始状态（瞬间） |
| `fade-enter-active` | 元素整个插入过渡阶段（持续一段时间） |
| `fade-enter-to` | 插入过渡的目标状态（过渡结束后移除） |
| `fade-leave-from` | 元素被移除前的初始状态 |
| `fade-leave-active` | 元素整个移除过渡阶段 |
| `fade-leave-to` | 移除过渡的目标状态 |

mode是模式，out-in表示旧元素先离开，新元素再进入(in-out就先进入再离开，不写就默认同时)。

那么现在css样式就应该为
```css
.fade-enter-active,
.fade-leave-active {
  transition: opacity 0.5s ease;
}
.fade-enter-from,
.fade-leave-to {
  opacity: 0;
}
```
插进来的时候，出去的时候都经历一个透明度的缓慢改变动画即缓入缓出：进入时透明度改为0，移除时默认透明度变成1，触发这个动画。
