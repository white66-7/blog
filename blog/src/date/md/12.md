## 字体
首先是字体，在正常的项目中字体一般放在前端文件夹中。网络好的情况下，网页一下子加载出十MB级的ttf字体文件不成问题，网络差的情况下，会加载网页最为原始的字体。加载好后突然变成实际的字体。
### 转SVG图标
第一种解决办法是将带有显眼且无法变动这两个特点的区域的字体直接转为SVG形式，举个例子来说：我的入屏动画有一个"一路向北的站点"描写动画，这段文字每次进入网页都会播放让后台加载东西,完全就可以转为SVG形式。

为了应用这个方法，我使用的工具是PS，就是那个广为人知的批图软件。创建一个适宜宽高的透明画布，按T键创立一个文字区域，然后选一个喜欢的字体，接着右键转换为形状，最后选择导出为SVG就可以了。
![操作](/messages/12/text.webp)

这样会得到一个html格式的文件，选择用记事本打开复制全部的代码，这就是得到的SVG表达式。

哦对了,如果你要用的字体是从网上下载下来的，要右键安装，PS才会显示可用。
### 字体文件压缩
可这样还是避免不了加载字体文件，既然这样。可以把字体文件加载逻辑改一下，原本是一下子把全部加载出来然后逐个对应渲染，现在可以是每次要渲染哪些就拿哪些，缓存这些，下次要拿不必加载直接从缓存区里拿到。

实现下来要靠终端运行下面的语句
```bash
npx cn-font-split -i No.289-ShangShouJiangHuShuFaTi-2.ttf -o ./sliced-font
```
这里的命令符是npx原因是npx可以使用临时下载这里的cn-font-split到本地缓存，执行完语句就删掉，不占内存。-i后面对应的是你的字体文件全名，-o后面跟着的是下载到哪个文件夹中

然后去得到的文件夹中找一下result.css文件打开，看看它最后一行的font-family是什么
```css
font-family: "ShangShouJiangHuShuFa";
```
如果是Vue框架就去index.html的head中加个全局链接
```html
<link rel="stylesheet" href="/text/ancient-font/sliced-font/result.css">
```
后面想用这个字体直接引用font-family对应的值就好了。

如果觉得它font-family的值太难写了，也可以换成自己喜欢的，在result.css文件中按ctrl + F全局查找，输入font-family，然后把后面的值全部换成你想要的就可以了。
