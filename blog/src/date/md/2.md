## 最大Bug
值得一提的题外话是为什么漏洞会叫Bug-飞蛾呢？原因是早期编程其实非常原始，所谓的计算机完全靠继电器组成，这个黑色，巨大又温暖的机器会吸引昆虫。

1947年9月，佛马克2型故障继电器中拔出了一只飞蛾，飞蛾拔出后计算机就恢复了运行，因此当计算机故障或程序错误都称为bug。

我的最大Bug是每次我的歌曲靠点击或拖拽存入时，我直接在数据库里塞进去了一份同样的文件。
```typescript
t.objectStore(S_STORE).put({
    id: s.id,
    signature: s.signature,
    name: s.name,
    artist: s.artist,
    originalFileName: s.originalFileName,
    directoryId: s.directoryId,
    file: s.file   //存的是 File 对象
});
```
在歌曲数量极少的情况下当然是可行的，但是一个歌曲文件flac格式大概在20多MB的量级，而IndexedDB只支持5GB的数据存量。
